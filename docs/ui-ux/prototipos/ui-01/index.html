Propuesta UI-01

Un prototipo separado de FresaPOS. No tiene acceso a usuarios, ventas, caja o servicios de la aplicación.

Prueba navegación, temas, preferencias y paneles. Los controles de negocio muestran vistas de muestra o permanecen deshabilitados.

El resumen no inventa indicadores. Los productos e importes del POS son ficticios y estáticos. No se autentica, agrega, calcula, cobra ni exporta.

Inter se sirve localmente; licencia OFL de la tipografía.

Sin conexión a la base de datos

Formulario de producto · muestra

Propuesta de agrupación visual. Ningún campo se guarda.

Producto de muestra

Vista de selección. No se agrega ningún producto ni cambia el total.

Cobro · vista de muestra

Sin cobro real. Importes fijos para revisar la presentación.

La revisión, autorización y confirmación originales no se sustituyen con este prototipo.

Confirmación · muestra

Una acción crítica debe conservar su contexto y mecanismo original.

Esta muestra no reemplaza confirmaciones, PIN, contraseñas o permisos de la aplicación.

Exportaciones existentes

Se conserva el acceso visual a las exportaciones. Sus generadores, contenido y límites quedan fuera del rediseño.
