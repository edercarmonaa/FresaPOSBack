# Contratos anteriores a UI-07A

Seis vistas de Catálogo copiadas del estado real al iniciar UI-07A, antes de modificarlas. Se preserva también la entrega UI-06 que todavía no tenía commit. `FixtureData.php` contiene únicamente datos ficticios de pruebas, sin consultas.

La comparación renderiza las vistas antiguas con su propia paginación y helper de errores mediante un namespace independiente. Comprueba seis perfiles de permiso, cinco estados, dos vistas y límites de paginación. Se normalizan valores booleanos HTML y el tipo implícito text; se comparan nodos de texto significativos para no confundir sangría con contenido.

El SVG de QA es una muestra vectorial identificada, sin relación con el formato de subida admitido en producción. El formulario conserva JPEG, PNG y WebP y su validación de servidor.
